Privacy Policy

Local Browser Storage: Dhand Stationery runs strictly in your web browser. All cart items, demo accounts, and sample orders reside inside your browser's localStorage.

No Remote Data Collection: No personal details, credit cards, or passwords are transmitted to external servers.

Device Specific: Clearing your browser cache will reset demo orders and carts.

Cloud Computing Project Overview

Project Title: Dhand Stationery — Business-Oriented E-Commerce Website

Subject: Cloud Computing (Frontend Architecture & Static Cloud Deployment)

Target Host: Netlify (Serverless static web hosting)

Key Technical Highlights:

  • Complete 4-page architecture (Home, Shop, Cart/Checkout, Login/Account)
  • 44+ unique products with real photographs from the shop
  • Client-side state management using HTML5 localStorage
  • Dynamic catalog filtering, search, sorting, and pagination
  • Realistic checkout flow with Indian phone and PIN-code validation
